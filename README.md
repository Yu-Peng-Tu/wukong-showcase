# 大圣 · 景深呼吸

一个以东方叙事为主题的桌面 Web 2.5D 视觉实验。项目以原创概念图和人工分层深度图为基础，使用 Three.js ShaderMaterial 实现轻微景深视差、远景柔化和克制的环境循环，用于展示视觉设计、图像分层与 WebGL 前端实现能力。

## 在线演示

- 公开展示版：https://fkbqco4v4qii2.ok.kimi.link
- 当前版本：1a1aff03-0152-8488-8000-0000ea91326f（2026-11-06 发布）
- 线上为完整作品集长页，包含“作品 / 解构 / 过程”导航、设计命题、镜头检查、技术说明和制作复盘。
- 页面保留近景点击、焦点切换、鼠标景深视差与自动循环，不包含公开编辑和状态保存入口。
- 线上完整版使用独立的完整作品集实现；本仓库保留单屏视觉实验源码、素材和验收资料。

## 效果与边界

- 保留全身背影、红色披风、金箍棒、天宫军阵与夕照云层的完整构图。
- 鼠标移动仅产生轻微、平滑的景深反馈，不劫持页面操作。
- 这是原图驱动的 2.5D 展示，不是可自由绕看的完整三维人物，也不包含真实布料或云层物理模拟。
- 视觉首屏以桌面 16:9 为目标，完整页面可向下浏览，但不做全设备适配。

## 技术实现

- Three.js / WebGL
- JavaScript + ShaderMaterial / GLSL
- 人工分层深度图与人物 / 披风分层素材
- 三层深度视差、焦点切换与九点柔化
- 完整线上版使用 Vite 静态构建
- 本仓库的单屏实验保留 Edit3D 本地开发与预览工具

## 本地运行

要求 Node.js 22.12 或更高版本。

```bash
npm install
npm run dev
```

检查与构建：

```bash
npm run check
npm run build
```
