# 大圣·天兵压境——个人作品集首屏设计简报

## 当前定位

这是个人求职作品集的第一个网页视觉案例，不是企业官网、游戏或独立互动 Demo。首屏负责证明视觉选择、版式、克制的动态设计与前端实现能力；完整案例正文和后续作品将在作品集页面中继续建设。

## 视觉基准

唯一视觉基准为用户提供的 `docs/ref/大圣背影_红色披风_天兵压境.jpg`，2048×1152。保留全身背影、完整红色披风、金箍棒、前景岩石、天宫军阵和夕照云层，不再使用半身大圣图。

## 首屏版式

- 左上：`SELECTED WORK / 01`，建立作品集阅读顺序。
- 左下：`大圣 · 天兵压境`，利用岩石与云层的暗部保证可读性。
- 标题下方：`网页视觉作品 · 东方叙事与景深`，明确作品属性。
- 人物和披风保持画面主体，不添加大片卡片、营销文案或复杂导航。

## 动态与交互

- 仅保留 4 秒无缝环境循环，没有长镜头或镜头切换。
- 自动动态为数像素级视差、远景柔化与披风微动态。
- 鼠标移动只提供轻微、平滑的景深反馈，不显示操作教学。
- 移除暂停、复位、快捷键、滚轮调参与双击复位，不劫持正常网页操作。

## 制作方式

- 原图：用户提供的高质量展示纹理。
- 深度：`scripts/prepare_cinematic.py` 针对全身背影新图重新绘制人工分层深度图。
- 渲染：Three.js ShaderMaterial，结合自动时间、平滑鼠标向量、深度视差与九点柔化。
- 运行：Play 仅接收画布鼠标移动，不创建独立渲染循环。
- 比例：当前以桌面 16:9 作品首屏为目标，不做全设备适配。
- 响应式缩放仅作用于未注册内部平面，不写入用户编辑记录。

## 边界

这是原图驱动的 2.5D 展示，不是可自由绕看的完整三维人物。鼠标驱动的是图像视差与柔化，不是真实三维相机、布料或云层模拟。
